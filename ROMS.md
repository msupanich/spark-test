# Sega Master System ROMs

This directory contains ROM files for Sega Master System games.

## How to Add ROMs

1. Click the "Select ROM File" button on the main page
2. Navigate to your ROM file
3. Select the `.sms` or `.bin` file
4. Press "Start Game"

## Supported ROMs

| Game | File | Status |
|---|---|---|
| Phantasy Star | Phantasy Star (World).sms | Add your own |
| Alex Kidd | Alex Kidd in Shinobi World.sms | Add your own |

## Notes

- ROMs must be in `.sms` or `.bin` format
- Most ROMs range from 128KB to 1MB
- Some games may require BIOS files (not yet implemented)
